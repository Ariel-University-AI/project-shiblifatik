## 1. סקירה כללית

### מטרת המערכת

מערכת **ניהול משרד מדידות** היא אפליקציית Web מתקדמת המשרתת משרד מדידות קרקע. המערכת מאחדת את כל תהליכי העבודה של המשרד תחת ממשק אחד מרכזי:

- **רישום ופתיחת פרויקטים** — כולל כל הפרטים הנדרשים (גוש, חלקה, ישוב, מזמין, סוג עבודה, מחיר)
- **בדיקה אוטומטית מול מאגר פנימי** — לאיתור עבודות קודמות באותו מיקום
- **ניהול קבצי פרויקטים** — מבנה תיקיות לפי שנים עם קישורים לקבצים רלוונטיים
- **מעקב עובדים** — מה כל אחד עשה, איזה עבודות סיים, ומדידת זמן פר משימה
- **דוח יומי** — סיכום של כל פעילות יום העבודה עם פירוט זמנים

### תרחיש שימוש טיפוסי

```
1. מגיע לקוח עם בקשה לפיצול חלקה בגוש 100 חלקה 50 בישוב "נצרת"
2. המהנדס פותח "פרויקט חדש" וממלא את הפרטים
3. המערכת בודקת במאגר הפנימי (Excel) — ומוצאת עבודה דומה מ-2021
4. מושמעת התראה + קישור לתיקיית הפרויקט הישן
5. המנהל מקבל התראה ומחליט אם להמשיך או לקשר לפרויקט ישן
6. ההנדסאי יוצא לשטח, פותח שעון זמן ומתחיל מדידה
7. בסוף היום נוצר דוח יומי עם כל הפעילות
```

## 3. תפקידי המשתמשים

### 3.1 מנהל (Manager)

**תיאור:** ראש המשרד, אחראי על כל הפעילות

**הרשאות:**
- גישה מלאה לכל המודולים
- קבלת התראות על כפילויות
- צפייה בדוחות של כל העובדים
- ניהול משתמשים (הוספה/עריכה/השבתה)
- ייבוא וייצוא נתונים
- מחיקת פרויקטים ומשימות
- ניהול הגדרות מערכת

**תצוגה ייחודית:**
- לוח מחוונים ראשי עם כל הסטטיסטיקות
- התראות דחיפה על פרויקטים כפולים
- צפייה ב-Timeline של כל הצוות

---

### 3.2 מהנדס (Engineer)

**תיאור:** עובד משרדי בכיר, אחראי על עיבוד מקצועי

**הרשאות:**
- פתיחת פרויקטים חדשים
- עריכת פרויקטים קיימים
- הצמדת קבצים לפרויקטים
- רישום משימות עצמיות
- צפייה בדוחות אישיים
- ייצוא נתונים

**מוגבלות:**
- אינו יכול למחוק פרויקטים
- אינו יכול לנהל משתמשים

---

### 3.3 שרטט (Draftsman)

**תיאור:** עובד משרדי, אחראי על ייצור מסמכים ותשריטים

**הרשאות:**
- צפייה בפרויקטים
- עדכון סטטוס משימות שרטוט
- רישום משימות עצמיות
- צפייה בדוחות אישיים

**מוגבלות:**
- אינו יכול לפתוח פרויקטים חדשים
- אינו יכול לעריכת פרטי מחיר

---

### 3.4 הנדסאי שטח (Field Technician)

**תיאור:** עובד שטח, מבצע מדידות בפועל

**הרשאות:**
- צפייה בפרויקטים שהוקצו לו
- עדכון סטטוס מדידה (התחלה/סיום)
- שימוש בשעון מדידת זמן
- רישום הערות שטח
- צפייה בדוחות אישיים

**מוגבלות:**
- אינו רואה מחירים
- אינו יכול לפתוח פרויקטים
- גישה מוגבלת לנתוני מאגר

## 6. קלט — Input

### 6.1 טופס פרויקט חדש — שדות קלט מלאים

| שדה | סוג | חובה | אימות | תיאור |
|-----|-----|------|-------|--------|
| `name` | טקסט | ✅ | מינ' 3 תווים | שם הפרויקט |
| `block` | מספר | ✅ | 1–99999 | מספר גוש |
| `parcel` | מספר | ✅ | 1–9999 | מספר חלקה |
| `subParcel` | מספר | ❌ | 1–99 | תת-חלקה |
| `settlement` | טקסט | ✅ | מינ' 2 תווים | שם הישוב |
| `region` | רשימה | ❌ | מרשימה מוגדרת | אזור גיאוגרפי |
| `client.name` | טקסט | ✅ | מינ' 2 תווים | שם מזמין |
| `client.phone` | טקסט | ❌ | פורמט ישראלי | טלפון |
| `client.email` | מייל | ❌ | פורמט מייל | כתובת מייל |
| `workType` | רשימה | ✅ | מרשימה מוגדרת | סוג העבודה |
| `price.net` | מספר | ✅ | > 0 | מחיר ללא מע"מ |
| `price.vat` | מספר | אוטומטי | 0–100% | אחוז מע"מ |
| `price.gross` | מספר | אוטומטי | מחושב | מחיר כולל מע"מ |
| `assignedTo.engineer` | עובד | ❌ | מרשימת עובדים | מהנדס אחראי |
| `assignedTo.fieldTech` | עובד | ❌ | מרשימת עובדים | הנדסאי שטח |
| `dates.dueDate` | תאריך | ❌ | עתידי | תאריך יעד |
| `priority` | רשימה | ✅ | דחוף/רגיל/נמוך | עדיפות |
| `notes` | טקסט ארוך | ❌ | מקס' 1000 תווים | הערות |

FUNCTION checkDuplicate(block, parcel, settlement, workType):
    
    // שלב 1: חיפוש ב-DB הפנימי (LocalStorage)
    internalMatches = DB.projects.filter(
        project.block    == block    AND
        project.parcel   == parcel   AND
        project.settlement == settlement
    )
    
    // שלב 2: חיפוש בקובץ ה-Excel (אם יובא)
    excelMatches = excelDB.filter(
        row.block      == block    AND
        row.parcel     == parcel   AND
        row.settlement == settlement
    )
    
    // שלב 3: קבוע חומרת הכפילות
    allMatches = internalMatches + excelMatches
    
    IF allMatches.isEmpty():
        RETURN { found: false }
    
    exactMatch = allMatches.filter(p => p.workType == workType)
    
    IF exactMatch.notEmpty():
        severity = "ERROR"    // אדום — אותו גוש/חלקה ואותו סוג עבודה
    ELSE:
        severity = "WARNING"  // צהוב — אותו גוש/חלקה, סוג שונה
    
    // שלב 4: שליחת התראה למנהל
    IF severity in ["ERROR", "WARNING"]:
        sendAlertToManager(allMatches, severity)
    
    // שלב 5: בדיקת קיום קובץ בארכיון
    FOR match IN allMatches:
        archivePath = findInArchive(match.block, match.parcel, match.year)
        match.archivePath = archivePath
    
    RETURN {
        found: true,
        matches: allMatches,
        severity: severity
    }
```

```
FUNCTION generateDailyReport(date):
    
    tasks = DB.tasks.filter(task.date == date)
    
    IF tasks.isEmpty():
        RETURN EmptyReport(date)
    
    report = {
        id: "RPT-" + date,
        date: date,
        summary: {},
        byEmployee: [],
        byProject: [],
        alerts: []
    }
    
    // סיכום כללי
    report.summary = {
        totalTasks:       tasks.count(),
        totalMinutes:     tasks.sum(t => t.durationMinutes),
        tasksCompleted:   tasks.filter(t => t.status == "הושלם").count(),
        tasksInProgress:  tasks.filter(t => t.status == "בתהליך").count(),
        projectsHandled:  tasks.map(t => t.projectId).unique().count(),
        activeEmployees:  tasks.map(t => t.employeeId).unique().count()
    }
    
    // פירוט לפי עובד
    employees = tasks.map(t => t.employeeId).unique()
    FOR emp IN employees:
        empTasks = tasks.filter(t => t.employeeId == emp.id)
        report.byEmployee.push({
            employee: emp,
            tasks: empTasks,
            totalMinutes: empTasks.sum(t => t.durationMinutes),
            completed: empTasks.filter(t => t.status == "הושלם").count()
        })
    
    // פירוט לפי פרויקט
    projects = tasks.filter(t => t.projectId != null).map(t => t.projectId).unique()
    FOR proj IN projects:
        projTasks = tasks.filter(t => t.projectId == proj.id)
        report.byProject.push({
            project: proj,
            tasks: projTasks,
            totalMinutes: projTasks.sum(t => t.durationMinutes)
        })
    
    // התראות של אותו יום
    report.alerts = DB.alerts.filter(a => a.date == date)
    
    // שמירה
    DB.set_report(report)
    
    RETURN report
```

function calcDuration(startTime, endTime) {
    const [sh, sm] = startTime.split(':').map(Number);
    const [eh, em] = endTime.split(':').map(Number);
    const totalMinutes = (eh * 60 + em) - (sh * 60 + sm);
    return Math.max(0, totalMinutes);
}

function formatDuration(minutes) {
    const h = Math.floor(minutes / 60);
    const m = minutes % 60;
    return `${h}:${String(m).padStart(2, '0')}`;
    // 255 → "4:15"
}
```

## 23. שאלות נפוצות

**ש: האם צריך שרת?**
ת: לא. האפליקציה עובדת לחלוטין בדפדפן עם LocalStorage.

**ש: מה קורה אם נסגר הדפדפן?**
ת: הנתונים נשמרים ב-LocalStorage ויהיו זמינים בפתיחה הבאה.

**ש: האם ניתן לשתף נתונים בין מחשבים?**
ת: לא אוטומטית. ניתן לייצא גיבוי ולייבא במחשב אחר.

**ש: כמה נתונים ניתן לאחסן?**
ת: LocalStorage מוגבל ל-5–10 MB. לאלפי פרויקטים, מומלץ גיבוי קבוע.

**ש: מה מפתח הכפילות?**
ת: גוש + חלקה + ישוב. שילוב זה חייב להיות ייחודי לאזהרת כפילות.

**ש: כיצד מבצעים גיבוי?**
ת: הגדרות → ייצוא → "💾 גיבוי מלא" → שומר קובץ .json.

**ש: האם ניתן לשנות את אחוז המע"מ?**
ת: כן — הגדרות → מע"מ → הזן אחוז (ברירת מחדל: 17%).
