## סקירה כללית

המערכת מאפשרת לצוות משרד מדידות לנהל את כל פעילות המשרד במקום אחד:

- **דשבורד ראשי** — תצוגת KPI: פרויקטים פתוחים, משימות תקועות, דד-ליין קרוב
- **ניתוח נתונים (EDA)** — חקירה חזותית של נתוני עבודות 2025–2026
- **מודל AI** — חיזוי זמן מדידה לפי מאפייני הפרויקט
- **ניהול פרויקטים** — הוספה, עדכון סטטוס, הקצאת מטפל, זיהוי כפילויות גוש/חלקה
- **ניהול משימות** — Kanban, מעקב שעות, ייצוא Excel

## התקנה והפעלה

### דרישות מקדימות

- Python 3.9 ומעלה
- pip

### התקנה

```bash
# שכפול הפרויקט
git clone <repo-url>
cd antigrafity

# התקנת תלויות
pip install -r requirements.txt
```

### הפעלה

```bash
streamlit run streamlit_app.py
```

האפליקציה תיפתח אוטומטית בדפדפן בכתובת: `http://localhost:8501`

### requirements.txt

```
streamlit>=1.32.0
pandas>=2.0.0
plotly>=5.18.0
openpyxl>=3.1.0
scikit-learn>=1.4.0
joblib>=1.3.0
```

## נתונים

### קובץ עיקרי: `data/2025_cleaned.csv`

נתוני עבודות מדידה לשנת 2025. מכיל שדות כגון:
- מס' עבודה, שם לקוח, גוש, חלקה, מקום
- מטפל, סטטוס, הצעת מחיר
- זמן מדידה (שעות), תאריך התחלה, יעד סיום, תשלום

### `projects.csv`

נוצר ומנוהל ע"י עמוד `4_ניהול_פרויקטים`. עמודות:
`מס עבודה, שם לקוח, גוש, חלקה, מקום, מטפל, סטטוס, הצעת מחיר, זמן מדידה, תאריך התחלה, יעד סיום, תשלום שהתקבל`

### `tasks.csv`

נוצר ומנוהל ע"י עמוד `5_משימות`. עמודות:
`שם המשימה, סטטוס, אחראי, פרויקט, חברה, לקוח מקושר, דד ליין, שעות מדווחות, שעות שבוצעו, תאריך יצירה, תאריך סגירה, הערות`

## מודל ML

המודל (`models/model.pkl`) מאומן על נתוני עבודות היסטוריים ומחזיר **חיזוי זמן מדידה** לפי:
- גוש וחלקה (מספר תתי-חלקות)
- מחיר הצעה
- סוג עבודה

**אימון מחדש:**
```bash
python dev/train_model.py
```
